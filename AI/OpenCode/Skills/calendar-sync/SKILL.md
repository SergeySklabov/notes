# Calendar Sync

Управление календарём через CalDAV (SOGo Astralinux).

Скрипты и примеры команд - см. `assets/`.

## Правила работы

- При поиске свободного слота проверяй календарь пользователя через `calendar-detail.sh`
- Если время не указано явно, предложи варианты пользователю
- При создании встречи с участниками добавляй их email через `--attendee`
- Для recurring-событий (Обед, daily и т.д.) UID обычно одинаковый для всех повторений. Изменять через override с RECURRENCE-ID
- Участников добавляй через `--attendee`, не в description
