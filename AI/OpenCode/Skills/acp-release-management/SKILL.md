# ACP Release Management

Управление релизами ACP (Astra Cloud Platform), генерация заметок по компонентам, ведение протоколов встреч.

## Использование

Загрузи скилл когда нужно:
- Собрать эпики релиза ACP из Jira
- Сгенерировать/обновить заметки в Obsidian по компонентам
- Проверить блокеры и статусы эпиков
- Оформить протокол встречи/статус-митинга из транскрибации
- Обновить статусы задач в компонентных файлах по итогам встречи

---

## 1. Поиск эпиков релиза

Jira Project = AIC, issuetype = Запрос, customfield_36803 (Возможные релизы) = {id версии}.

ID версий ACP:
- ACP 2.2.0 (НОЯБРЬ 2026): 49706

## 2. Маппинг компонентов

Приоритет:
1. **Явный оверрайд** (`epic_override`)
2. **Assignee -> компонент** (`assignee_to_comp`)
3. **Первый компонент из поля Компоненты** (fallback)

| Assignee | Компонент |
|---|---|
| Михаил Перевалов | `[SCP]` |
| Виталий Козловский | `[IAM]` |
| Максим Югай | `[TMS]` |

Оверрайды: AIC-1816 -> `[TMS]`

## 4. Генерация файлов компонентов

Скрипт: `assets/generate_epic_files.py`

```
python3 assets/generate_epic_files.py
```

На выходе для каждого компонента - 2 файла:
- `Компоненты/{Name}/{Name}.md` - сущность компонента
- `Компоненты/{Name}/ACP 2.2.0.md` - эпики релиза

Шаблон: `assets/epic-file-template.md`

**Формат задач, терминология, структура протоколов - см. AGENTS.md -> разделы 4, 5.**

## 5. Коллеги

Создаются автоматически в `Работа/Astra/Команда/Команда Платформы AC/{Name}.md`.

## Важные замечания

- Link type: `'Блокада'` или `'Blocks'`
- Блокеры - `inwardIssue` (AIC заблокирован)
- Changelog - `expand=changelog`
- Статусы подзадач: Backlog, "в работе" (lowercase), In Progress, SELECTED FOR DEVELOPMENT
- Assignee из live-данных Jira
