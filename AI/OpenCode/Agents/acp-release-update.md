description: Собрать статус релиза ACP 2.2.0 из Jira, проверить блокеры, обновить заметки по компонентам
---

Загрузи скилл acp-release-management и выполни:

1. Найди эпики ACP 2.2.0 (issuetype = Запрос, fixVersion = ACP 2.2.0 (НОЯБРЬ 2026), id версии 49706)
2. Сгруппируй по компонентам согласно маппингу assignee_to_comp
3. Для каждого эпика проверь: статус, ответственного, подзадачи, последние комментарии, блокеры, историю изменений за последние 2 недели

4. Обнови файлы в двух форматах:

   **Формат A: Компонентные файлы** (`Работа/Astra/Платформа Astra Cloud/Компоненты/<компонент>/ACP 2.2.0.md`)
   Для каждого эпика:
   - Заголовок: `## [AIC-XXX](url) [!]` (❗ если не было изменений 2+ недели, иначе без иконки)
   - **Статус:** текущий статус
   - **Ответственный:** `[[ссылка|Имя]]`
   - **Автор:** кто создал
   - **Подзадачи:** для каждой подзадачи — ссылка, статус, ответственный, иконка (🟢 в работе, 🔵 Backlog, ✅ Готово)
   - **Последнее изменение:** только последнее по дате, развёрнуто
   - **Комментарии:** ссылка на протокол встречи, если обсуждалось
   - **⛔ Блокеры:** если есть

   **Формат B: Prep-заметки** (`Работа/Astra/Встречи/Протоколы встреч/*/Prep *.md`)
   Для раздела `### Обновления в Jira`:
   - `**[AIC-XXX](url)** - Название`
   - `- **Статус:** статус`
   - `- **Ответственный:** Имя`
   - `- **Последний комментарий (ДД.ММ, ЧЧ:ММ):**` — последний комментарий развёрнуто
   - `- **Предыдущий комментарий (ДД.ММ, ЧЧ:ММ):**` — предпоследний, если есть
   - Для подзадач: вложенно под родительским эпиком

5. Сформируй краткую сводку: сколько эпиков, сколько в работе/блокере/готово, новые блокеры, новые комментарии
