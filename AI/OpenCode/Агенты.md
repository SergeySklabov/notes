Способы запустить агента:

**1. Автоматический запуск (чаще всего):** Основной агент (build) сам решает, когда позвать субагента. Если вы пишете «найди где реализована аутентификация» — он сам делегирует `explore` или `librarian`. Это работает через инструмент `task`.

**2. Явный вызов через @mention в TUI:**

```
@sisyphus спланируй рефакторинг модуля X
@hephaestus добавь авторизацию по JWT
@oracle почему падает этот тест?
@librarian найди как работает Effect.gen
@prometheus давай обсудим архитектуру
@metis оцени мой план
```

| Ситуация                     | Агент         |
| ---------------------------- | ------------- |
| Большая задача с подзадачами | `@sisyphus`   |
| «Сделай X, разбирайся сам»   | `@hephaestus` |
| Нужно обсудить план          | `@prometheus` |
| Сложный баг / архитектура    | `@oracle`     |
| Поиск доки/примеров          | `@librarian`  |
| Ревью плана                  | `@metis`      |
