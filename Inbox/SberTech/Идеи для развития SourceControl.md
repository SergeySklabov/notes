# Links

# Description

## Must Have (Обязательные)

- **Хостинг Git-репозиториев**  
    Поддержка приватных и публичных репозиториев, работа с большими монорепозиториями, поддержка LFS.
    
- **Контроль доступа и интеграция с корпоративными системами**  
    LDAP/Active Directory, SSO (SAML, OAuth2), детальная ролевая модель, аудит действий пользователей.
    
- **CI/CD Pipeline**  
    Встроенные пайплайны, поддержка кастомных runner-ов, возможность интеграции с корпоративными облаками и on-premise инфраструктурой.
    
- **Code Review и Merge Requests**  
    Удобный интерфейс для ревью кода, inline-комментарии, approval workflow, шаблоны MR.
    
- **Управление задачами и проектами**  
    Issue tracker, Kanban/Board, автоматизация переходов, интеграция с внешними системами (Jira, 1C, ServiceNow).
    
- **Безопасность и соответствие требованиям**  
    Сканирование уязвимостей, контроль секретов, соответствие ФЗ-152, поддержка ГОСТ-алгоритмов шифрования.
    
- **Локализация и поддержка русского языка**  
    Полная русификация интерфейса, поддержка документации на русском.
    
- **On-premise установка и поддержка контейнеризации**  
    Возможность развертывания в частных облаках, Kubernetes, Docker.
    

## Should Have (Желательные)

- **Миграция из других систем**  
    Импорт из GitLab, GitHub, Bitbucket, поддержка массового переноса репозиториев и задач.
    
- **Интеграция с DevOps-инструментами**  
    Поддержка Prometheus, Grafana, ELK, внешние webhook-и, API для автоматизации.
    
- **Гибкая настройка уведомлений**  
    Email, мессенджеры (Telegram, корпоративные чаты), интеграция с SIEM.
    
- **Управление артефактами и пакетами**  
    Встроенный registry для Docker-образов, Maven/NuGet/NPM-репозитории.
    
- **Масштабируемость и отказоустойчивость**  
    Кластеризация, резервное копирование, автоматическое восстановление.
    

## Could Have (Можно рассмотреть)

- **Визуализация DevOps-метрик**  
    Дашборды для мониторинга качества кода, скорости релизов, покрытия тестами.
    
- **Встроенный Wiki и документация**  
    Хранение проектной документации, поддержка Markdown, контроль версий.
    
- **Мобильное приложение**  
    Для просмотра задач, уведомлений и быстрого реагирования.
    
- **Механизмы геймификации**  
    Бейджи, рейтинги за активность в ревью и коммитах.
    

## Won’t Have (В ближайших релизах не планируется)

- **Публичный marketplace расширений**  
    Открытая платформа для сторонних плагинов и интеграций.
    
- **Интеграция с западными SaaS**  
    Slack, Google Cloud, AWS и другие сервисы, ограниченные в РФ.
    
- **Облачная SaaS-версия для SMB**  
    Фокус на крупные Enterprise и on-premise решения.
