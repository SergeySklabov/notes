# Description
К релизу добавили важные обновления:
🔲 инструменты безопасности;
- Сканер секретов
- Анализ зависимостей
- Сводная статистика по найденым проблемам

🔲 чат с ИИ-помощником;
Можно прямо в IDE задать вопрос, попросить сгенерировать код, юнит тесты или документацию.
Доступно в плагинах VSCode и JetBrains

🔲 зеркалирование с GitHub;
- Можно зеркалировать репозитории с GitHub со всеми сущностями: pull requests, issues, brunches 
- Появилась регулярная синхронизаиция внешних Git репозиториев
- Компании могут подключаться через SSO и централизовано управлять доступов

🔲 CI/CD;
- Поддержка бранч-ревью и ревью-политик
- Self-hosted runners

🔲 федеративный доступ и не только.
