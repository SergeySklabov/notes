# Description
![[Pasted image 20241215102801.png]]
- Нужно задавать цель спринта. Спринт на 1-2 недели.

- Ежедневные стендапы на 5-7 минут. Нужно понять
	- Что делали вчера?
	- Что будем делать сегодня?
	- Какие блоки есть? Что мешает быть продуктивнее?
- Это позволит сосредточиться только на главном

- После спринта - нужно ревью результатов и только **при необходимости ретро** ретро.
- Это позволит выработать групповую ответственность

- Нужно выбирать задачи по принципу **минимальные усилия - максимальный результат**
- Задачи выбирать по критериям:
	- Быстро исполнимо - Одного действия достаточно чтобы решить вопрос
	- Реализуемо без бюджета
	- Мощный эффект от результата
	- Можно делегировать
	- Понятно как делать
	- Расширить узкое горлышко / уберет главное ограничение
