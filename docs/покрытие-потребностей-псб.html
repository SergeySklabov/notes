Что входит в MVP ACP 2.2.0 (ноябрь 2026)

КомпонентСоставСтатус
Портал самообслуживания (SCP)~15 UC из ~50. ВМ (CRUD), диски, публичные образы, дашборд (стат-карточки), SSH-ключи✅ MVP
IaaS-оркестратор~10+ UC. REST API для ВМ, дисков, образов🟡 Зависимость (предоставляет API)
Брест/CrystalCRUD ВМ, диски, образы (базовые)🟡 Зависимость (предоставляет API)
IAMSSO (OAuth 2.0/OIDC), отображение роли из JWT🟡 Зависимость (предоставляет API)
SDNТолько дефолтная сеть тенанта (Brest read-only)🟡 Частично
МониторингТолько стат-карточки на дашборде🟡 Минимально

11 потребностей ПСБ vs MVP

Потребность 1 — Папки/области вместо VDC

Модель VDC → области/папки с разной ролевой моделью

АспектОтвет
В MVP?❌ Нет
ПочемуИзменение модели VDC — это доработка BillManager (ISPsystem) или появление TMS
Что реально в MVPЕдиный VDC на тенант. Никаких папок/областей
Когда ждать🟡 2.3+ (BillManager) или 2027 H1+ (TMS)
Что сказать заказчику«В ноябре — один VDC на тенант. Разделение на области — после доработки BillManager или появления TMS»

Потребность 2 — Группировка ресурсов в VDC

Ресурсы сплошным списком, нельзя объединить в группы

АспектОтвет
В MVP?❌ Нет
ПочемуНет модели тегов/групп в IaaS-оркестраторе
Что реально в MVPПлоский список ВМ с сортировкой и поиском
Когда ждать🟡 2.3+ (если IaaS-оркестратор добавит теги) также зависит от TMS
Нужно уточнить а что именно ПСБ хочет видеть - общий список ресурсов в проекте, сколько фактически потребляется, сколько денег потрачено
Что сказать заказчику«В ноябре — плоский список с поиском. Группировка — после появления тегов в платформе»

Потребность 3 — Роли Админ / Админ ИБ

Администратор клиента (управление) и Администратор ИБ (только просмотр)

АспектОтвет
В MVP?❌ Нет
ПочемуРолевая модель убрана из ВИ (PULSE W28). Per-service RBAC зависит от TMS
Что реально в MVPЕдиная роль: пользователь с полным доступом к своему тенанту
Когда ждать🔵 2027 H2+
Что сказать заказчику«В ноябре — одна роль пользователя. Разделение Админ/Админ ИБ — не ранее 2027»

Потребность 4 — Логирование действий админов

Кто, когда, какие действия на ВМ. Логи доступны Администратору ИБ

АспектОтвет
В MVP?❌ Нет
ПочемуАудит есть на стороне IaaS, но UI логов в ЛК — post-MVP. Нет endpoint для SCP
Что реально в MVPIaaS логирует действия. Но отображения логов в ЛК — НЕТ
Когда ждать🟡 2.3+ (если IaaS-оркестратор сделает read-only endpoint)
уточнить у компонентов по логированию. Должен быть sys.log для выгрузки во внешний SIEM
Что сказать заказчику«Логирование на стороне платформы есть. Интерфейс логов в ЛК — в следующем релизе»

Потребность 5 — Фильтрация/поиск ВМ по имени и адресу

Список ВМ не позволяет искать ВМ по имени/адресу

АспектОтвет
В MVP?🟡 Зависит от API
ПочемуЕсли IaaS-оркестратор поддерживает фильтрацию (search/query params) — делаем. Если нет — только клиентский поиск по загруженному списку
Что реально в MVPКлиентская фильтрация по имени (в браузере). Серверная фильтрация — если API позволяет
Когда ждать🟢 MVP (клиентская) / 🟡 2.3+ (серверная)
Что сказать заказчику«Поиск по имени в списке — будет. Поиск по IP — после доработки API оркестратора»

Потребность 6 — Отображение сетей, MAC, интерфейсов ВМ

В списке ВМ видеть сети, число интерфейсов, IP и MAC-адреса

АспектОтвет
В MVP?🟡 Зависит от API
ПочемуНужен endpoint GET /vm/{id}/nics от IaaS-оркестратора
Что реально в MVPЕсли API есть — покажем. Если нет — только IP из основной модели ВМ
Когда ждать🟢 MVP (если API готов) / 🟡 2.3+
Что сказать заказчику«Уточняем у команды оркестратора — будут ли детальные данные по сетевым интерфейсам»

Потребность 7 — Поле «Описание» для ВМ

Добавить поле описания для служебной информации

АспектОтвет
В MVP?🟡 Зависит от API
ПочемуНужно поле description в модели ВМ IaaS-оркестратора + PATCH endpoint
Что реально в MVPЕсли модель данных позволяет — сделаем. Если нет — post-MVP
Когда ждать🟢 MVP (если API готов) / 🟡 2.3+
Что сказать заказчику«Поле описания — технически простая задача. Решается после расширения модели данных»

Потребность 8 — Управление датацентрами

Администраторы заказывают/изменяют/удаляют датацентры

АспектОтвет
В MVP?❌ Нет
ПочемуФункция админ-портала, которого нет даже в проекте
Что реально в MVPЦОД отображается в информации о ВМ (read-only)
Когда ждать🔵 2027 H1+
управление тенантами
Что сказать заказчику«Управление ЦОД — функция оператора платформы. В 2026 — через администратора, в 2027 — через админ-портал»

Потребность 9 — Смена пароля

Пользователь меняет пароль через интерфейс БИЛЛ

АспектОтвет
В MVP?🟡 Через IAM
ПочемуРешение 26.06: смена пароля — в IAM-портале, не в ЛК
Что реально в MVPКнопка «Сменить пароль» → редирект на IAM-портал
Когда ждать🟢 MVP (редирект на IAM)
Что сказать заказчику«Смена пароля — через корпоративный портал IAM. В ЛК будет кнопка перехода»

Потребность 10 — Истекший пароль — не пускать

АспектОтвет
В MVP?❌ Не в ЛК
ПочемуФункция IAM — проверка при аутентификации
Что реально в MVPIAM должна обеспечить блокировку при истекшем пароле
Когда ждать🟢 MVP (задача на IAM, CF-4460)
Что сказать заказчику«Это проверка на уровне IAM при входе — не функция портала»

Потребность 11 — VNC-прокси через БМ

БИЛЛ должен проксировать VNC-консоль

АспектОтвет
В MVP?🟡 Через .vv файл
ПочемуVNC через .vv файл (virt-viewer) — делает IaaS-оркестратор. Браузерная VNC — 3.0+
Что реально в MVPКнопка «Подключиться» → скачивание .vv файла → открытие в virt-viewer
Когда ждать🟢 MVP (через virt-viewer) / 🔵 3.0+ (в браузере)
добавить что-то про Spice. Проработка SPICE
Что сказать заказчику«Консоль — через нативное приложение virt-viewer. Браузерная консоль — в 2027+»

Что честно сказать заказчику

В ноябре 2026 вы получите портал для пользователя:

ЕстьНет
✅ Создавать, запускать, останавливать, удалять ВМ❌ Роли Админ / Админ ИБ
✅ Создавать и прикреплять диски❌ Группировка по папкам/тегам
✅ Выбирать ОС из публичных образов❌ Снапшоты и бэкапы
✅ Смотреть дашборд (стат-карточки)❌ Floating IP и Security Groups
✅ Заходить по SSH❌ Браузерная VNC
✅ Единый вход (SSO)❌ Смена пароля (только редирект)
✅ Дефолтная сеть❌ Квоты, биллинг, потребление
✅ Поиск по имени в списке ВМ❌ Свои ISO/образы

Остальное — в 2027:

  • 2027 H1 (2.3+): отображение сетей/MAC/IP, описание ВМ, квоты (read-only), базовый мониторинг
  • 2027 H2+ (3.0+): ролевая модель, браузерная VNC, снапшоты, свои образы, полный SDN
