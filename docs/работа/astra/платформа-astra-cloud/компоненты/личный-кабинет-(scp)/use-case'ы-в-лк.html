Jul 08, 20265 min read

Портал самообслуживания

MVP

Доступ

  • UC-OPP-021 — Войти на Портал. Аутентификация пользователя и вход в рабочее пространство тенанта.
  • UC-OPP-022 — Выйти из Портала. Завершение сессии.

Виртуальные машины (жизненный цикл)

  • UC-SCP-028 — Создать ВМ на основе образа. Основной сценарий создания: ВМ создаётся из образа, шаблоны от пользователя скрыты.
    • Нужен метод API для получения списка образов - сам список образов мы предварительно загружаем
  • UC-SCP-003 — Изменить виртуальную машину. Изменение конфигурации существующей ВМ.
  • UC-SCP-004 — Просмотреть подробную информацию о ВМ.
  • UC-SCP-005 — Удалить виртуальную машину.

Сети

  • UC-SCP !нужно завести номер! — Создать виртуальную сеть в Бресте. !нужно завести номер UC-SCP! Под это API нет
  • Нужен метод API для получения списка сетей
  • Есть метод API, но НЕТ UC: - прикрепить уже созданную сеть к ВМ
  • Есть метод API, но НЕТ UC: - открепить уже созданную сеть от ВМ
  • UC-SCP !нужно завести номер! — Изменить виртуальную сеть в Бресте. !нужно завести номер UC-SCP! Под это API нет НЕТ UC: Удалить виртуальную сеть.

Диски

  • Создание
  • Список Дисков
  • Детальная информация
  • Удаление

Вторая итерация

Виртуальные машины (жизненный цикл)

  • UC-SCP-002 — Создать виртуальную машину из шаблона. Создание ВМ через портал. Под это API нет НЕТ UC: Создание из диска

Образы

  • UC-SCP-025 — Просмотреть каталог образов. Список доступных образов для создания ВМ.
  • UC-SCP-029 — Настроить политики доступа к образу. Базовый уровень: кастомный образ, загруженный в тенант, доступен в рамках этого тенанта. Гибкие политики доступа — отдельная проработка. НЕТ UC: Загрузить образ в тенант — импорт кастомного образа.

Префиксы тенантов (SDN)

Нужен комментарий от Андрея Иволги. К чему вообще относится? Есть подозрение, что это чисто технический сценарий.

  • UC-SCP !нужно завести номер! — Просмотреть список анонсов префиксов тенанта. !нужно завести номер UC-SCP!
  • UC-SCP !нужно завести номер! — Просмотреть список префиксов внешней сети. !нужно завести номер UC-SCP!
  • UC-SCP !нужно завести номер! — Создать анонс префикса тенанта. !нужно завести номер UC-SCP!
  • UC-SCP !нужно завести номер! — Удалить анонс префикса тенанта. !нужно завести номер UC-SCP!

Снимки/снапшоты

  • UC-SCP-006 — Создать мгновенный снимок ВМ. Снапшот состояния ВМ.
  • UC-SCP-007 — Просмотреть список снимков ВМ. Перечень снапшотов.
  • UC-SCP-008 — Удалить снимок ВМ. Удаление снапшота.
  • UC-SCP-009 — Восстановить снимок ВМ. Откат ВМ к снапшоту.

Резервное копирование

  • UC-SCP-018 — Создать задание резервного копирования. Настройка задания РК.
  • UC-SCP-020 — Выполнить резервное копирование ВМ. Запуск РК.
  • UC-SCP-021 — Просмотреть список резервных копий. Перечень копий.
  • UC-SCP-016 — Восстановить резервную копию ВМ. Восстановление из копии.
  • UC-SCP-017 — Отменить задание резервного копирования. Остановка задания РК.
  • UC-SCP-022 — Удалить резервную копию. Удаление копии.

Управление образами

  • UC-SCP-024 — Создать пользовательский образ. Есть вопрос востребованности — возможно не во 2-й итерации, а позже. Нужно обсуждение.

  • UC-SCP-027 — Изменить образ.
  • UC-SCP-030 — Создать образ на основе ВМ.
  • UC-SCP-031 — Удалить образ.
  • UC-SCP-032 — Создать копию диска.
