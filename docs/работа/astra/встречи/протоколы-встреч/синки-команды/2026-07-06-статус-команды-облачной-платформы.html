Риски

  • IaaS-оркестратор (SDN-сети в ЛК) - нет решения по предоставлению SDN-сетей пользователям в новом ЛК. IaaS-оркестратор не попадёт в октябрьский релиз. Риск: полгода остаёмся с ручным режимом
  • TROK integration - блокер по resize boot-устройства. Не решить до конца недели -> TROK не в 2.2
  • IAM multi-tenancy - зависимость от архитектуры (обсуждение 07.07)
  • Orchestrator - mock-реализация для MVP; риск - разработка может отвергнуть

AAR

1. Что планировали?

Еженедельная синхронизация статуса: sprint goals -> side activities -> escalation -> dev interaction

2. Что получилось?

  • Прошли по всем 8 участникам, каждый показал статус
  • Выявлены 2 блокера + 1 архитектурный риск
  • Не удалось удержаться в тайминге (13 мин на Сергея + cross-cutting)
  • SDN/Orchestrator дискуссия заняла ~15 мин внутри синхронизации

3. Почему?

  • Много административных вопросов в начале
  • Cross-cutting темы всплывают ad-hoc
  • Нет строгого timeboxing
  • Не все показывали доску (Александр без телефона, Максим не с доски)
