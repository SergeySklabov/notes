# Description
Древо #metrics 
В качестве #NSM - предлагается взять общее количество успешно завершенных на платформе конвейеров CI/CD.

Основная ценность Платформы Полного Цикла Разработки ПО - быстрая реализация качественного и безопасного софта. Это периодичный процесс (привязанный к релизному циклу) состоящий из ряда последовательных этапах. Почти на каждом из этих этапов происходит запуск того или иного пайплайна.
![[Pasted image 20241127231717.png]]
Потениально можно рассмотреть в качестве NSM - количество релизов, но есть компании, которые релизят, например, раз в пол-года. Тем не менее там все равно команды на dev, test, uat окружениях должны часто гоняться пайплайны (в противном случае им Платформа не сильно полезна). 

Таким образом чем больше команда прогоняет этапов разработки в период времени (с учетом устраненных препятствий в виде ожидания доступов или свободных ресурсов) - тем более она эффективна. И следовательно тем ценнее для них Платформа, как инструмент позволяющий быть настолько эффективной.

Балансирующими метриками предлагаю выбрать

- Количество обращений в Поддержку. Например, конвейеры отработали успешно, но софт собрался с ошибками. Команда разработки пытается разобраться и обращается либо к команде Платформы либо к ВК, как к поставщику.
- Количество зафейлиных пайплайнов
    - Они могут быть зафейлены по причине того, что они кривые - тут мы можем на это влиять предоставляя шаблоны и рекомендации по из кастомизации, либо же каким-то образом предоставляя механизм проверки корректности
    - Они могут быть зафейлены по причине, что сами тесты не прошли -тут мы можем на это влиять предоставляя рекомендации, что может быть улучшено в коде
