# Description
По итогам [встречи](https://confluence.vk.team/pages/viewpage.action?pageId=1335268623):

VK Security Gate сейчас используется как SaaS внутри периметра ВК для всех команд.
Для поставки решения on-prem необходимы доработки.

Помимо самого инструментария ценность для внешних клиентов представляет проведенная командой Security Gate аналитика по частоте тех или иных запросов в рамках используемых инструментов/сканеров.

В качестве инструментов/сканеров используется open-source решения – для подключения платных сканеров (например, от Positive Technologies или Solar) необходимы доработки.

К изначальным вопросам:

- Переделака под логирование (отдать логгер)
- Вопрос по Ролевым Доступ (доработка ролевки – посмотреть)
- Аутенитификация
- Доработка Админок
- Доработка Гайдов

Добавились:

- Доработка API для интеграции
- Интеграция с Dev Platform – проработка e2e сценариев

Коллеги, тут поправьте плиз меня если где-то наврал.  
 

Но ключевой вопрос – готовность идти в коммерческое использование.

  

Ожидаем информацию:

- Доработка Security Gate для поставки on-prem (какие ресурсы для этого нужны и сколько примерно это может занять) -  - 1фронт, 3 бекенд (6 месяцев);
- Возможность использования Security Gate как SaaS через VK Public Cloud для клиентов ВК Облака - тут кажется сильно проще. Так как быстрее можно развернуть и поддерживать;
- Сколько нужно для поддержки (как on-prem так и SaaS);
- Добавление платных сканеров (Positive Technologies/Solar) - Платные сканеры индивидуальные все (тут не бывает прям одинакого). Если очень примерно - то месяц на сканер
