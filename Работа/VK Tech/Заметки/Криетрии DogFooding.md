# Description
- Команда использует Gitlab развернутый и управляемый Dev Platform полностью перейдя с CorpGitlab для задач:
	- Написания, изменения и храрения кода Dev Platform
	- Проверка кода (код-ревью)
	- Запуск сборок и деплоев
- Команда использует Nexus развернутый и управляемый Dev Platform полностью перейдя с Corp Nexus для задач:
	- Хранилище куда собираются артефакты и пакеты, создаваемые командой
	- Хранилище из которого берутся артефакты и пакеты для последующего деплоя
	- Возможность использовать Анонимный доступ в Nexus используют и другие команды
- Команда использует виртуальные ресурсы управляемые Dev Platform - corp.cloud для тестирования
	- Деплой на эти ресурсы осуществляется через конвейры CI/CD на Платформе 
- Команда проверяет качество кода используя инструмент SonarQube, управляемый из Платформы
- Команда использует подключенные/интегрируемые внешние инструменты для улучшение качества работы:
	- Allure TestOps
	- Security Gate
	- Jira 
- Команда готовит
	- Описание перехода с корп инструментах на Dev Platform с указанием шагов и последствий (возможно факапов - потом можно будет использовать на fuckup nights)
	- Отчет о работе на Dev Platform с описанием сценариев, которые ранее применялись на корп инструментах с указанием на сколько Dev Platform соотвествует прошлому опыту (если нет - почему?)
		- Рекомендации что в платформе можно добавить для улучшения опыта
