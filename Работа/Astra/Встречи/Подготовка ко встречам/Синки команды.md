## Формат

На старте - общие задачи по спринту. Далее для каждого участника:
- **Итоги прошедшего спринта** - какие цели выполнены, какие нет, блокеры, side-активности
- **Цели на следующий спринт** - что планируется, потенциальные блокеры
- **Задачи с прошлых встреч** - статус каждой (сгруппированы по датам)
