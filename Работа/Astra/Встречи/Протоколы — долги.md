# Протоколы — долги

> Борд по стенограммам встреч. Показывает активности, которые **прошли**, но не зафиксированы протоколом.
> Разметка живёт во frontmatter стенограмм — см. [[Tag Lifecycle — работа с тегами (1)]].

## Семейство тегов

- `#protocol/missing` — встреча прошла, протокола нет. **Долг, нужно разобрать**
- `#protocol/skip` — сознательно без протокола (1-2-1, черновые записи). Не тревожить
- `#protocol/done` — протокол написан, ссылка в поле `Протокол:`

Правило перехода (в духе Tag Lifecycle: теги не удаляются, а заменяются):
`protocol/missing` → `protocol/done` + заполнить `Протокол:` вики-ссылкой.
