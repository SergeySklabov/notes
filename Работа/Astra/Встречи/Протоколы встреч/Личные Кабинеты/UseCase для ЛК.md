# Контекст

## Решения (23.07)
- Контекст поменялся: **ПСБ** как реальный заказчик - приоритет ЛК вырос
- Первый шаг: моки админского портала (аналогично порталу самообслуживания)
- Сценарии - на основе моков
- MVP: single-tenant. Мультитенантность и переключение - следующие итерации

## Решения (15.07)
- **SSO через IAM** - в MVP ✅
- **ЖЦ ВМ** (создать/список/изменить/удалить + питание) - в MVP
- **Сети** - VLAN, 1 интерфейс, 1 адрес - в MVP
- **Диски** - persistent-образы через IaaS Orchestrator - в MVP
- **Тенантный контекст** - показывать принадлежность в MVP
- **IAM + Brest** - не в MVP, после октября (требование ДИБ)
- **Терминология:** APIM -> IaaS Orchestrator, «инстанс» -> «ВМ», «прикрепить сеть» -> «добавить сетевой интерфейс»

- **Интеграция IAM + Brest** - после октября (требование ДИБ)
