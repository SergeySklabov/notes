## Протокол встречи

**Тема:** Рабочее совещание по документации и справочному центру - актуализация документов, уязвимости, системные требования, миграция справочного центра, подготовка к ребрендингу
**Участники:** @Сергей Склабовский, @Оксана Кондратенко, @Дмитрий Тайлаков

### Контекст

Рабочее совещание по документации ACP после релиза 2.1. Обсуждение текущих задач: запросы на документацию, справочный центр, уязвимости, ПМИ/ФТТ, сертификация и ребрендинг. Релиз 2.1 - отправная точка для актуализации документации.

### 1. Запросы на документацию

- @Андрей Серов запрашивает документацию по резервному копированию.
- Обсудили общий пул запросов на корректировку документации — нужен полный список актуальных документов для платформы.
- @Сергей Склабовский начинает с темы документации, чтобы получить полный список.

### 2. Документ по уязвимостям (CVE)

- Не все исходники найдены для документа по уязвимостям.
- @Сергей Склабовский попросит коллег из RnD помочь с поиском и сбором исходников.
- **Позже (28.07, синк с On-prem):** решено — единый список CVE не делаем. Каждый сертифицированный компонент публикует свой формуляр в ЛК.

### 3. ПМИ (Программно-методическая инструкция)

- Не хватает перечня проверок для ПМИ.
- @Оксана Кондратенко продолжит подготовку документов для прохождения ПМИ.
- Информация по платформе разрозненная — нужен сбор всей информации.

### 4. ТТ и ФТТ (Технические требования)

- Неясность в требованиях к ТТ.
- @Дмитрий Тайлаков поможет с формированием ТТ.
- Нужен сбор информации от пользователей ТТ.

### 5. Справочный центр

- Некоторые разделы не актуализированы.
- @Оксана Кондратенко организует проверку новых разделов.
- **Ребрендинг и миграция:** переезд на новый движок + смена домена. Работа начнётся с 10 августа.
- **Конвертация:** есть технические сложности с конвертацией — будет попытка конвертации части справочного центра.

### 6. Сертификация

- Большой объём работы по сертификации.
- Планирование — на этапе проектирования, сроки не определены.
- Сертификация будет определяться по мере готовности компонентов.

### 7. AICBUG

- @Оксана Кондратенко будет координировать работу с AICBUG.

## AAR (After-Action Review)

### 1. Что планировали?
Обсудить текущие задачи по документации, справочному центру, ПМИ, сертификации после релиза 2.1.

### 2. Что получилось?

**Удачно:**
- Определён план по справочному центру (миграция с 10.08, ребрендинг)
- Распределены задачи по ПМИ и ФТТ
- Синхронизировались по AICBUG — Оксана координирует
- Релиз 2.1 зафиксирован как база для документации

**Неудачно:**
- Не все исходники по уязвимостям найдены (разрозненны по RnD)
- Сертификация — объём не оценён, сроки не определены
- Конвертация справочного центра — технические сложности

### 3. Почему?
- Исходники CVE разрозненны по разным командам RnD
- Этап сертификации — предварительный, зависит от готовности компонентов
- Оксана — один человек на несколько направлений

### 4. Что будем делать иначе?
- **Следующая встреча** через 2 недели (~31.07) — сверить прогресс
- @Сергей Склабовский запросит исходники у RnD в ближайшие дни
- @Оксана Кондратенко стартует миграцию справочного центра с 10.08
