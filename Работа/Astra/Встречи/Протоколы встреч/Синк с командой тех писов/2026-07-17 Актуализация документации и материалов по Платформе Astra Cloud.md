**Участники:** @Сергей Склабовский, @Оксана Кондратенко, @Дмитрий Тайлаков

### Контекст

Рабочее совещание по документации ACP: обсуждение текущих задач после релиза 2.1, запросы на документацию, справочный центр, уязвимости, ПМИ/ФТТ, сертификация и ребрендинг. Запланирована следующая встреча через 2 недели.

### Запросы на документацию

@Андрей Серов запрашивает документацию по резервному копированию. Обсудили общий пул запросов на корректировку документации.

### Документ по уязвимостям

Не все исходники найдены. @Сергей Склабовский попросит коллег из RnD помочь с поиском и сбором.

### ПМИ (Программно-методическая инструкция)

Не хватает перечня проверок для ПМИ. @Оксана Кондратенко продолжит подготовку документов для прохождения ПМИ.

### ТТ и ФТТ (Технические требования / ФТТ)

Неясность в требованиях к ТТ. @Дмитрий Тайлаков поможет с формированием ТТ. Нужен сбор информации от пользователей ТТ.

### Справочный центр

Некоторые разделы не актуализированы. @Оксана Кондратенко организует проверку новых разделов. Запланирован переезд на новый движок и смена домена (ребрендинг). Есть сложности с конвертацией справочного центра - будет попытка конвертации части. Работа начнётся с 10 августа.

### Сертификация

Большой объём работы. Планирование работы по сертификации - будет определяться на этапе проектирования.

### AICBUG

@Оксана Кондратенко будет координировать работу с AICBUG.

### Релиз 2.1

Создание релиза 2.1 как отправная точка для актуализации документации.
