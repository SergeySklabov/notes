# Формат

Ежемесячная встреча ACP ↔ On-prem. Цель — синхронизировать ожидания, выявить совместные активности, разграничить зоны ответственности. По необходимости частота может быть увеличена.

На встрече:
- **Повестка** — готовится заранее, рассылается до встречи
- **Обсуждаемые темы** — ожидания, зависимости, блокеры между ACP и On-prem
- **Решения и задачи** — фиксируются в протоколе, трекаются в этой заметке

# Контекст предыдущей встречи (28.07)

## Решения
- **Единый список CVE** — не делаем. Каждый сертифицированный компонент публикует свой формуляр при релизе в ЛК. Если заказчик запросит — соберём ✅
- **Сценарий «частичная доставка компонентов»** — пока не рассматриваем. Переход на 2.1 = новая платформа + миграция данных ✅
- **Два сценария миграции:** (а) 1.3.1 → 2.1, (б) Brest → 2.1 (через 4.0.2 + доставка). Обе задачи в бэклог RnD ✅
- **ALD → FreeIPA:** обратную миграцию не делаем. Новые установки с FreeIPA ✅
- **Лицензии:** переориентируемся на манифесты (BillManager за скобками) ✅
- **Приёмка фич RnD:** если участвовал в требованиях → демо-приёмка. Критичные — блокирующая ✅
- **Бэкап платформы:** целевое Brest (конец года), промежуточное Rubackup (августовский патч). Сертифицированного РК до конца года нет ✅
