## Решения по тикетам

- Выбор нескольких сетей в BILLmanager при создании ВМ (L2, запрос ПСБ) - в новой версии BILLmanager 6.144 работа с сетями переделана (можно подключать 2 интерфейса). Версия пойдёт в патч-релиз ACP 1.3.2 (август). Запрос закрываем, т.к. дублируется с [AICBUG-151](https://jira.astralinux.ru/browse/AICBUG-151) - реализация в рамках 151/обновления. Проверить подтягивание сетей из шаблона в 6.144 - @Василий Текучев
- Отдельно организовать встречу по поддержке кастомной версии BILLmanager 6.144 у ПСБ (кто и как поддерживает до выхода 2.1) - @Вадим Николаев передаёт @Михаил Кочетков (его зона ответственности); участники: Александр Лещев, Алексей Калядин. Нужна матрица совместимости версий
- Процессное: в тикетах обязательно указывать заказчика/организацию (метка/поле) - чтобы FR падал на нужного лида (Паблик -> @Александр Кудрявцев, Приват -> @Станислав Черков)
- Репликация между СХД (СОД) - механизм базируется на [BACK-62](https://jira.astralinux.ru/browse/BACK-62), реализация в Brest 4.0.2 -> при обновлении закрываем - @Сергей Склабовский проставит
- [AICBUG-129](https://jira.astralinux.ru/browse/AICBUG-129) (Secure Boot) - правка в Brest реализована в 4.0.2 (ACP 2.1). В 3.3.4 сейчас не запланирована; @Дмитрий Попенов сделает по подтверждению. Уточнить у ИБ обновление Brest 3.3 -> 3.3.4 (сертифицированность миноров)
- [AICBUG-149](https://jira.astralinux.ru/browse/AICBUG-149) (через Terraform/API можно расшарить образы/ВМ всем заказчикам - ИБ против) - нужно ограничить шаринг рамками своего тенанта. @Василий Текучев + @Станислав Черков уточняют у безопасников, не сломает ли доработка аттестацию/сертификацию (синк по коммуналке во вторник 10:00). Описать в тикете доступные варианты
- [AICBUG-145](https://jira.astralinux.ru/browse/AICBUG-145) (связь квот BILLmanager ↔ Brest) - переводим в баг с низким приоритетом (нет бизнес-заказчика), реализуем в своём темпе в рамках платформы
- RBAC-модель / работа с группами клиентов (старая история, автор Виктория) - нет бизнес-заказчика -> в бэклог (без заказчика жить не будет)
- [AICBUG-154](https://jira.astralinux.ru/browse/AICBUG-154) (некорректный подсчёт занятого места в Ceph -> биллинг завышен из-за снапшотов) - переводим в баг, берём в работу. Использовать механизм Ceph для подсчёта реально используемого места. Реализация в новой версии - Лайка 2.0 / ACP 2.2 (Brest 4.0.3). Проверить наличие связанной задачи в Brest - @Денис Черкесов / @Александр Лещев
