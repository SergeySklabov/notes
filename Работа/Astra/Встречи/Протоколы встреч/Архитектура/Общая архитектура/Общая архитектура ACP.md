# Контекст предыдущей встречи (21.07)

## Решения
- ✅ **Без BillManager** - Сергей принял решение: целевая архитектура без BillManager, биллинг сбоку
- Квоты - технический инструмент оператора, привязаны к тенантам
- Квоты ≠ метринг - разные сущности
- Zero Trust - авторизация на каждом сервисе
- BillManager сам подтвердил: оркестрация не их путь

## Нерешённые вопросы
- Целевая архитектура без BillManager - не нарисована (Андрей перерисует к след. неделе)
- Usage metering - отложен
- Organization Manager - внутри ТМС или отдельно
- API-слой на схемах - обещан в след. серии
