# Знания

### Миграция
- Минорный апгрейд (3.3.3 → 3.3.4) — софт-миграция, без прерывания.
- Мажорный апгрейд (3.3.3 → 4.0.2) — прерывание (разные версии ALSE 1.7 / 1.8).
- OpenNebula — текущая версия: **6.0.8**.
- С августа 2026 ALSE 1.7 — end of support (только платные фиксы).

### Безопасность
- ACP не использует все функции безопасности Бреста: запросы на ВМ — от одного служебного пользователя в BillManager.
- У Бреста есть дискреционный режим → ACP не аттестуем.

### DR (катастрофоустойчивость)
- Каскадная репликация — возможна в H2'26? (не подтверждено, зависит от TROK 2.1).
- DR у ACP (Брест LVM) лучше, чем у OrionSoft — конкурентное преимущество.
- В Брест 4.0.2: каскадной репликации нет (только ручной режим).
- Развитие DR/СРК: распределение резервных копий в хранилище TROK.

### Резервное копирование
- Можно подключить внешнюю систему РК — Брест будет знать и блокировать операции с ВМ.
- Проблем не с бэкапом, а с восстановлением — нужна информация от компонентов.

### Брест LVM
- Доработки для РК.
- vGPU: сейчас подключаемое устройство, нужно как разделяемый ресурс хоста.
