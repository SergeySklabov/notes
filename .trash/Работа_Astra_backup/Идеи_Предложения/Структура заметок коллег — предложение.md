# Структура заметок коллег — предложение

## Текущая проблема

Заметки коллег (`Работа/Astra/Команда/Команда Платформы AC/`) сейчас — это одна секция `# Description`, куда попадает всё подряд:

- **Знания** — факты о системах, архитектуре, процессах (например, «минорный апгрейд — софт-миграция, мажорный — с прерыванием»). Это permanent-информация, актуальна всегда.
- **Задачи** — чекбоксы с тегами и дедлайнами.
- **История встреч** — датированные блоки с повесткой и договорённостями.
- **Чат-логи** — скопированные сообщения из корп.мессенджера целиком.
- **Вопросы** — то, что нужно спросить при следующей встрече.

Всё это перемешано: факт от мая, задача от апреля, чат от июля. Когда нужно быстро подготовиться к встрече — приходится перечитывать всё подряд.

## Предложение

### 1. Чёткая структура заметки

```markdown
---
tags:
  - коллега/vir
  - коллега/брест
phone:
department:
---

# Знания
Факты, архитектурные решения, договорённости «на будущее».
Не привязаны к дате — актуальны всегда.

# Открытые вопросы
Вопросы, которые не получили ответа.
По мере ответа — переносим в #Знания или удаляем.
Можно вынести в отдельный Dataview-запрос.

# Последние обсуждения
### 2026-07-04 | Встреча / Чат / Звонок
**Повестка:** ...
**Договорились:**
- ...
**Стало известно:**
- ...
**Открытые вопросы:**
- ...

### Дата | Тип контакта
... (повторяющийся блок)

# Задачи
```tasks
not done
tags include #Попенов_Дмитрий
sort by due
group by due
```
```

### 2. Каждая запись в #Последние обсуждения — по шаблону

Шаблон для вставки (можно сделать Obsidian Template):

```markdown
### YYYY-MM-DD | Встреча / Чат / Звонок / PBR
**Повестка:** ...
**Договорились:**
- [ ] ... #Фамилия_Имя #Astra_work 📅 YYYY-MM-DD
**Стало известно / Решения:**
- ...
**Открытые вопросы:**
- ...
```

Тип контакта (Встреча / Чат / Звонок / PBR) — чтобы визуально отличать.

### 3. Знания — наверх, отдельно от истории

- В начале заметки секция `# Знания` — факты, которые не потеряют актуальность.
- При появлении нового факта на встрече — сразу записываем в `# Знания`, а в историю пишем только ссылку `↑ факт добавлен в Знания`.
- Со временем `# Знания` растёт, `# Последние обсуждения` остаётся хроникой.

### 4. Чат-сообщения — не копировать verbatim, а саммаризировать

Вместо:

```markdown
Встречаемся в след чт/пт в офисе по определению с какой версии OpenNebula форкаться – не забудь плиз командировку оформить.
Если вдруг придет на ум какие еще фичи...
```

Писать:

```markdown
### 2026-06-29 | Чат
**Договорились:**
- [ ] Встреча в офисе чт/пт — определить версию OpenNebula для форка. Оформить командировку. #Попенов_Дмитрий
- [ ] До конца недели — список фич Бреста к ноябрю. #Попенов_Дмитрий 📅 2026-07-02
- [ ] Посмотреть шаблон видения, дать обратную связь. #Попенов_Дмитрий
- [ ] Поставить встречу до середины августа по презентации видения. #Попенов_Дмитрий
**Стало известно:**
- DR у ACP лучше, чем у OrionSoft
- Архитектурное ревью — 3 стадии: зачем → границы → финализация архитектуры
```

Копия чата — в архиве мессенджера, Obsidian — для решений и действий.

### 5. Дашборд «подготовка к встрече»

Если встреча с коллегой завтра — открываем его заметку и видим:

- **#Открытые вопросы** — что ещё не ответил.
- **#Знания** — контекст, чтобы не переспрашивать.
- **#Задачи (просроченные)** — что висит с его стороны / у него.
- **#Последние обсуждения (последние 1-2 записи)** — чтобы освежить.

### 6. Шаблон для новой заметки коллеги

Создать Obsidian Template `Работа/Astra/Команда/Команда Платформы AC/Шаблон коллеги.md`:

```markdown
---
tags:
  - коллега/
phone:
department:
position:
---

# Знания

# Открытые вопросы

# Последние обсуждения

# Задачи
```tasks
not done
tags include #Фамилия_Имя
sort by due
group by due
```
```

## Результат

| Было | Стало |
|------|-------|
| Одна секция Description на всё | 4-5 секций с чётким назначением |
| Факты теряются в хронологии | Знания в начале, всегда под рукой |
| Чат-логи загромождают заметку | Только решения и действия |
| Задачи и знания вперемешку | Задачи — отдельный блок |
| Подготовка к встрече — перечитать всё | Открытые вопросы + просроченные задачи + знания |
